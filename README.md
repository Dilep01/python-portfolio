# Dilep Kumar K — Python Portfolio

**[View the portfolio](https://dilep01.github.io/python-portfolio/)**

My Python full-stack portfolio, featuring SpendTrail, Enterprise Incident Investigation & Resolution Copilot, DocuMind AI, and RetailIQ. Based in Bengaluru, Karnataka.

## The website

The design uses charcoal, warm ivory, lime, and coral, with an original SVG sculpture, paper compositions, an animated radar, a document scan, and an illustrative forecast chart.

Each project includes a case study with its workflow, features, recorded validation, limitations, and repository. The website also includes my resume, experience, skills, and contact links.

## Run locally

Open index.html directly, or run npm run dev and visit http://127.0.0.1:4173. The optional server requires Node.js; there are no dependencies to install.

Run npm run check to check JavaScript syntax, internal links, local assets, project coverage, and accessibility hooks.

## Edit

- index.html: page content and project illustrations.
- styles.css: layout, typography, responsive styling, and animations.
- app.js: case studies, menu, motion preference, clock, and email-copy control.
- assets/: local fonts, artwork, and downloadable resume.
- scripts/: local server, checks, and original artwork generator.

## Hosting

GitHub Pages serves the root of the main branch. The site is static and needs no build step, API key, paid service, or sign-in. Relative asset paths support the /python-portfolio/ URL.

## Scope and accessibility

These are independent portfolio applications, separate from my testing employment. Project test counts are recorded validation evidence, not tests executed by the website. The project artwork and forecast chart are conceptual illustrations. See [content sources](CONTENT_SOURCES.md) for evidence boundaries.

The website supports mobile navigation, keyboard-accessible dialogs, Escape dismissal, focus restoration, reduced motion, and a pause-motion control. Manrope and Instrument Serif are bundled under the SIL Open Font License; license files are in assets/.
